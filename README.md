# 🤖 Jarvis — Personal AI Assistant

A personal AI assistant project inspired by **JARVIS from Iron Man**.

This project is built with Python and is designed as a modular assistant that can be extended with voice interaction, a graphical interface, and different assistant modules.

> 🚧 **Status:** Work in Progress — features and architecture may change as the project develops.

## ✨ Features

* 🎙️ Voice interaction
* 🖥️ Graphical user interface
* 🧠 Modular assistant architecture
* 💾 Data and memory storage
* 🐍 Python-based core
* 🧪 Separate test files for UI and voice functionality
* 🔧 Easy to extend with new modules

# 📁 Project Structure

```text
Jarvis/
│
├── .vscode/          # VS Code configuration
├── core/             # Core assistant functionality
├── data/             # Data and memory files
├── gui/              # Graphical user interface
├── modules/          # Additional assistant modules
├── main.py           # Main entry point
├── requirements.txt  # Python dependencies
├── test_ui.py        # UI testing
├── test_voice.py     # Voice functionality testing
└── README.md         # Project documentation
```

## 🛠️ Technologies

* **Python**
* **QML**
* **HTML / JavaScript**
* **PowerShell**
* **C++**
* Python libraries listed in `requirements.txt`

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shusovan-69/Jarvis.git
```

### 2. Open the project

```bash
cd Jarvis
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows CMD:

```bash
venv\Scripts\activate
```

PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Jarvis

```bash
python main.py
```

## 🧪 Testing

To test the UI:

```bash
python test_ui.py
```

To test voice functionality:

```bash
python test_voice.py
```

## ⚠️ Important

The `venv/` folder is a local Python virtual environment and normally **should not be uploaded to GitHub**.

Add it to `.gitignore`:

```gitignore
venv/
__pycache__/
*.pyc
.env
```
